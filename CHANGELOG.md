# История изменений

## 0.1.0

Первая версия MVP.

**Проверки.** 25 проверок профиля: доступность и HTTP (QC-001…005), структура по исходному HTML (QC-006…008, 011, 013),
ссылки (QC-012), браузерные проверки (QC-009, 010, 014…016), вход и регистрация без ввода данных (QC-017…019),
безопасные API-проверки по `GET` (QC-020…025). Браузер уточняет предупреждения по отрисованной странице; без Chrome
браузерные проверки получают `SKIPPED`.

**Запуск.** Веб-форма и консоль, подтверждение права на тестирование, фоновые запуски с прогрессом и остановкой,
страница результатов и страница каждой проверки, настройки `QAXRAY_*` с жёсткими границами.

**Отчёты.** Маскирование секретов на всех границах, черновики bug report для `FAILED` (Markdown, JSON), результаты для
Allure (ZIP), скачивание из интерфейса.

**Безопасность.** Политика адресов (только публичные), соединение с проверенным IP (защита от DNS rebinding),
прокси-сторож браузера, защита от CSRF, ограничение частоты и числа параллельных запусков, ограничение ответов и
тайм-ауты.

**Известные ограничения.** Результаты хранятся в памяти процесса до часа; один процесс; частота считается по адресу
соединения (за прокси нужно отдельное решение); YAML-документация API не читается; интерфейс не проверен
скринридером вручную; недоступный сайт отвечает около 50 секунд; остановка не прерывает идущий HTTP-запрос.
Решения и риски: [docs/decisions](docs/decisions).
