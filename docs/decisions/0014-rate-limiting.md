# ADR-0014. Ограничение частоты и числа параллельных запусков

Статус: принято. Дата: 2026-11-08.

## Контекст

Каждый запуск создаёт нагрузку на проверяемый сайт и на наш сервер (потоки, браузер). Защита от CSRF (ADR-0013)
не мешает человеку или скрипту отправлять форму много раз подряд. Нужно ограничить и скорость запусков, и их число
одновременно.

## Решение

1. **Одновременные запуски:** не больше `QAXRAY_MAX_PARALLEL_RUNS` (1–4, по умолчанию 2), прежнее ограничение
   хранилища (ответ 429, сообщение «слишком много одновременных запусков»).
2. **Частота:** не больше `QAXRAY_RATE_LIMIT_RUNS` запусков (1–30, по умолчанию 10) за скользящее окно
   `QAXRAY_RATE_LIMIT_WINDOW` секунд (10–600, по умолчанию 60) для одного адреса клиента. Класс `RateLimiter`
   (`app/services/rate_limiter.py`) не зависит от Flask, время подставляется в тестах.
3. **Ключ клиента** — адрес соединения (`remote_addr`). Заголовки `X-Forwarded-For` и подобные **не доверяются**:
   их подделка не обходит ограничение (есть тест). За обратным прокси все пользователи будут выглядеть одним клиентом;
   тогда понадобится отдельное решение о доверенном прокси.
4. **Что считается:** отправка формы, прошедшая проверку полей, до запуска (запуск с запрещённым адресом тоже
   считается: разрешение имён стоит ресурсов). Невалидные формы, остановка, скачивание и просмотр не ограничиваются.
5. **Ответ при превышении:** 429, заголовок `Retry-After`, форма с сохранёнными значениями и сообщением «повторите
   через N с». Заблокированные попытки в счёт не идут, блокировка не продлевается.
6. **Память ограничена:** не более 1000 ключей, устаревшие забываются, давно не использованные вытесняются.
   Вытеснение даёт нападающему с очень многими адресами обход счётчика, но число одновременных запусков остаётся
   ограниченным.
7. Границы значений жёсткие (как у остальных настроек); отключить ограничения нельзя.

## Последствия

Счётчики живут в памяти процесса и сбрасываются перезапуском. Для нескольких процессов нужно общее хранилище
(вместе с хранением запусков). Публикация за прокси (PB-054) требует решения о ключе клиента.
