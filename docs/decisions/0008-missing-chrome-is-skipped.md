# ADR-0008. Chrome не установлен: браузерные проверки пропускаются

Статус: принято. Дата: 2026-11-07.

## Контекст

Браузерные проверки (QC-009, 010, 014…019 и уточнение QC-006…013) требуют Chrome. На компьютере без Chrome они
получали `BLOCKED` («сбой среды»), а консоль возвращала код 1, хотя сайт здесь ни при чём, а проверки по HTTP и HTML
отработали нормально.

## Решение

1. **Новая ошибка `BrowserNotInstalledError`** (вид недоступного браузера). Исполнитель превращает её в `SKIPPED` с причиной
   «Chrome не найден: установите Google Chrome, и браузерные проверки заработают». `BLOCKED` остаётся для сбоев при
   работе браузера (не запустился, сеть, тайм-аут и т. д.).
2. **Как определяется, что Chrome нет.** Ошибка Selenium «Unable to obtain driver» одинакова и без Chrome, и без сети для
   загрузки драйвера, поэтому по её тексту их не различить. Chrome считается не найденным, только если одновременно:
   драйвер не получен (или нет исполняемого файла) **и** Chrome не обнаружен в стандартных местах установки (macOS:
   `/Applications` и `~/Applications`; Linux: `google-chrome`, `chromium` и аналоги в `PATH`; Windows: `Program Files`,
   `LocalAppData`; а также `CHROME_BIN`, `SE_BROWSER_PATH`, `SE_CHROME_PATH`). Любая другая ошибка запуска остаётся `BLOCKED`.
3. Уточнение QC-006…013 при отсутствии Chrome возвращает результат по HTML с пометкой «уточнение в браузере не
   выполнено» ([ADR-0010](0010-browser-refines-html-results.md)).
4. Код возврата консоли: `0`, если нет `FAILED` и `BLOCKED`.

## Проверено

Выполнен реальный запуск консоли с несуществующим путём к браузеру (Selenium по-настоящему не смог получить драйвер)
и подменой определения установки: 8 `PASSED`, 2 `WARNING`, 15 `SKIPPED`, **0 `BLOCKED`**, код возврата 0.

## Последствия

- Нестандартная установка Chrome (портативная копия, другой каталог) может быть принята за отсутствие, если одновременно
  не удалось получить драйвер: тогда нужно задать путь переменной `SE_BROWSER_PATH`.
- Без Chrome половина профиля пропущена: результат честный, но неполный; в причине сказано, как это исправить.
