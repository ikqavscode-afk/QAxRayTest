# ADR-0003. Известные риски безопасности первого релиза

Статус: принято. Дата: 2026-11-07.

## Контекст

Приложение принимает адрес и выполняет сетевые запросы, поэтому может быть использовано как
прокси к внутренним ресурсам (SSRF). Базовая защита реализована в `TargetPolicy` и
`SafeHttpClient` (см. ADR-0001, ADR-0002). Часть рисков осознанно оставлена на следующие этапы.

## Принятые риски и план

| Риск | Описание | Мера сейчас | План |
|---|---|---|---|
| DNS rebinding | Между проверкой адреса и соединением DNS-ответ может измениться: библиотека `requests` резолвит имя повторно | Проверка всех IP из DNS и каждого редиректа; запуск только локально или по списку разрешённых целей | Соединяться с уже проверенным IP (собственный транспортный адаптер) до публичной демо. Для браузера уже сделано прокси-сторожем ([ADR-0007](0007-browser-and-navigation-guard.md)); для HTTP-клиента сделано: [ADR-0015](0015-pinned-connection.md) |
| Нет CSRF-защиты формы | Сторонняя страница может отправить форму от имени пользователя | Сделано: токен сессии и проверка Origin ([ADR-0013](0013-csrf-protection.md)) | — |
| Нет ограничения частоты | Один клиент может запускать проверки без пауз | Сделано: ограничение по адресу клиента и числу параллельных запусков ([ADR-0014](0014-rate-limiting.md)) | — |
| Синхронный запуск | Запрос веб-формы ждёт завершения всех проверок | Тайм-ауты и лимиты клиента | Фоновое выполнение, прогресс и остановка (Sprint 3) |
| Текст ошибок в отчёте | Причина `BLOCKED` может содержать фрагменты адресов или ответов | В лог пишется только имя ошибки | Сделано: `Redactor` ([ADR-0011](0011-secret-redaction.md)) |
| Режим отладки Flask | Интерактивный отладчик даёт выполнение кода | Включается только флагом `--debug` | Не использовать вне локального компьютера |

## Последствия

До устранения первых трёх рисков публичная версия сервиса не выпускается; демонстрация допустима
только на собственной цели или на нейтральных адресах вроде `https://example.com`.
