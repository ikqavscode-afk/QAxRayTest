# ADR-0001. Технологический стек MVP

Статус: принято. Дата: 2026-11-07.

## Контекст

Нужен небольшой, законченный и безопасный MVP: пользователь вводит адрес сайта, адрес
документации API и базовый адрес API, подтверждает право на тестирование и получает результаты
стандартного профиля из 25 проверок, черновики bug report и Allure-отчёт.
Автор проекта владеет Python, pytest, requests, Selenium (POM), Allure и Flask.

## Решение

| Область | Выбор | Причина |
|---|---|---|
| Язык | Python 3.12+ (разработка на 3.14) | Единый язык для приложения и тестов |
| Веб-слой | Flask (application factory, Blueprints), Jinja2 | Известен автору, достаточно для простого UI |
| Модели данных | Pydantic v2 | Единые типизированные модели входа и результата |
| HTTP | requests за портом `HttpClient` | Простота; клиент заменяем без правок ядра |
| Браузер | Selenium за портом `BrowserPort` | Есть опыт POM; Playwright можно добавить вторым адаптером |
| Тесты | pytest, фикстуры, параметризация, маркеры unit/integration/ui | Практики из требований концепции |
| Отчёты | Allure (результаты формирует собственный адаптер) | Отчёт нужен и вне запуска pytest |
| Хранение | В памяти и JSON-файлы; SQLite позже | Не усложнять первый релиз |
| Качество | ruff, mypy (strict), pre-commit, GitHub Actions | Проверка при каждом изменении |

## Принципы

- `core` не импортирует Flask, Selenium и requests: зависимость идёт от контрактов (DIP).
- Новая проверка добавляется отдельным классом и регистрацией в каталоге; оркестратор не меняется (OCP).
- POM используется только для браузерных проверок; для HTTP/API есть клиенты и модели ответов.
- Конфигурация и секреты берутся из окружения; `.env` не хранится в git.
- Абстракции «на будущее» не создаются, пока не решают текущую задачу.

## Последствия

- Выбор Selenium можно пересмотреть отдельным ADR, если потребуется Playwright.
- FastAPI рассматривается позже для публичного API, когда оно понадобится.

## Не входит в MVP

Конструктор чек-листов, AI-помощник, мобильное тестирование, нагрузочное тестирование,
обход CAPTCHA и MFA, массовая регистрация, автоматический вызов всех методов API,
роли и тарифы.
