# ADR-0004. Конфигурация и жёсткие границы

Статус: принято. Дата: 2026-11-07.

## Контекст

Лимиты HTTP-клиента (тайм-аут, размер тела, перенаправления, повторы) были зашиты в код.
Их нужно настраивать, но приложение выполняет запросы к чужим адресам, поэтому настройка не
должна позволять отключить защиту или создать чрезмерную нагрузку.

## Решение

- Настройки читаются из переменных окружения `QAXRAY_*` в одном месте (`app/config.py`,
  модель `Settings`). Окружение передаётся аргументом, поэтому тесты изолированы.
- У каждого значения есть диапазон; значения вне границ отклоняются при запуске с названием
  переменной (консоль: код 2; веб: приложение не стартует).

| Переменная | Диапазон | По умолчанию |
|---|---|---|
| `QAXRAY_HTTP_TIMEOUT` | 1–30 с | 10 |
| `QAXRAY_MAX_BYTES` | 10 000–5 000 000 | 1 000 000 |
| `QAXRAY_MAX_REDIRECTS` | 0–10 | 5 |
| `QAXRAY_MAX_RETRIES` | 0–3 | 2 |
| `QAXRAY_RETRY_DELAY` | 0–5 с | 0,5 |
| `QAXRAY_BROWSER_PAGE_TIMEOUT` | 5–60 с | 20 |
| `QAXRAY_BROWSER_HEADLESS` | 0 или 1 | 1 |
| `QAXRAY_BROWSER_NO_SANDBOX` | 0 или 1 | 0 (только для одноразовых машин CI) |

- Настройки, отключающей политику адресов (защиту от запросов во внутренние сети), нет и не
  будет; это закреплено тестом.
- Файл `.env` приложение не читает (нет лишней зависимости); `.env.example` описывает переменные.
- Границы расширяются только осознанным решением с обновлением этого ADR.

## Последствия

- Неверное значение не заменяется молча значением по умолчанию: ошибка видна сразу.
- Конфигурация встроена в корень композиции (`bootstrap.py`), проверки о ней не знают.
