# ADR-0016. Укрепление веб-приложения и требования к развёртыванию

Статус: принято. Дата: 2026-11-08.

## Контекст

После релиза `v0.1.0` разобраны риски запуска на своём компьютере и публикации на сервере. Остались три класса угроз:
подмена DNS против самого приложения (запрос с чужим именем хоста на `127.0.0.1`), слабая защита страниц на стороне
браузера и перегрузка сервиса толпой разных клиентов или запуском без предела времени.

## Решение (реализовано)

1. **Проверка заголовка `Host`** (`app/web/security.py`): допустимы только имена из `QAXRAY_ALLOWED_HOSTS` (по умолчанию
   `localhost`, `127.0.0.1`, `[::1]`; без «*», портов и путей, не более 10). Остальные запросы, включая статику, получают
   400 до любой другой обработки. Порт не учитывается; имя в ответе не повторяется.
2. **Защитные заголовки** на каждом ответе: строгая `Content-Security-Policy` (`default-src 'none'`, скрипты и стили
   только свои, без `unsafe-inline`; `form-action 'self'`, `base-uri 'none'`, `frame-ancestors 'none'`), `nosniff`,
   `X-Frame-Options: DENY`, `Permissions-Policy` (камера, микрофон, геолокация, платежи, USB выключены),
   `Cross-Origin-Opener-Policy` и `Cross-Origin-Resource-Policy`, `Cache-Control: no-store` для динамических страниц,
   HSTS только по HTTPS. Тест следит, чтобы в шаблонах не появились встроенные скрипты, стили и обработчики событий.
3. **`Referrer-Policy: same-origin`, а не `no-referrer`.** При `no-referrer` браузер отправляет форму с `Origin: null`,
   и проверка CSRF (ADR-0013) отклоняет настоящий запрос пользователя. Это обнаружено только в живом браузере (тестовый
   клиент `Origin` не шлёт); тест закрепляет значение.
4. **Доверенный прокси** `QAXRAY_TRUSTED_PROXIES` (0–3, по умолчанию 0): число обратных прокси, чьим
   `X-Forwarded-For` и `X-Forwarded-Proto` доверяем (`ProxyFix`); берутся записи справа, поэтому добавленный клиентом
   префикс не обходит ограничение частоты. Заголовок `Host` из прокси не берётся.
5. **Общий предел запусков** на весь сервис: предел одного клиента × 3 за то же окно (ответ 429 «Сервис занят»). Толпа
   разных адресов больше не обходит ограничение по одному адресу.
6. **Предел времени запуска** `QAXRAY_MAX_RUN_SECONDS` (30–900, по умолчанию 300): по истечении срока запрашивается
   остановка, браузер закрывается, запуск получает статус `STOPPED` с частичным отчётом. Обычный запуск занимает секунды.
7. **Аудит зависимостей** отдельным недельным заданием `audit.yml` (`pip-audit`), не входящим в быстрый CI. Локальный
   аудит 42 пакетов на момент решения: известных уязвимостей нет.
8. **Профиль Chrome** проверен на живом запуске: браузер стартует с временным каталогом
   (`--user-data-dir=…/org.chromium.Chromium.scoped_dir.*`), а не с профилем пользователя.

## Требования к публикации на сервере (не реализованы, обязательны до открытия доступа)

- Запуск за обратным прокси по HTTPS с `QAXRAY_COOKIE_SECURE=1`, `QAXRAY_TRUSTED_PROXIES`, `QAXRAY_ALLOWED_HOSTS`,
  сервер приложений (например, gunicorn), а не сервер разработки Flask. Один процесс, пока запуски хранятся в памяти.
- **Изоляция Chrome:** отдельный контейнер или виртуальная машина без прав администратора, без доступа во внутренние сети
  и к службам сервера (исходящий трафик только в публичный интернет), лимиты памяти, процессора и числа процессов.
  Контейнерам часто нужен `--no-sandbox`: либо жёсткая изоляция всего контейнера, либо в первой версии браузерные
  проверки выключены (проверки получают `SKIPPED`).
- Решение о составе целей: по концепции публичная версия не проверяет любые адреса (своя демо-цель или список).
- Приватность: что и сколько хранится, текст для пользователей, обработка запросов на удаление (до включения хранения).
- Мониторинг и журнал злоупотреблений без личных данных, внешняя защита от перегрузки.

## Не сделано

Пауза между повторными запусками одной и той же цели, Dockerfile и сценарий развёртывания, проверка прав на цель
(владение сайтом), вход пользователей. Это отдельные решения.

## Последствия

Новые настройки ограничены жёсткими границами, отключить защиту ни одной из них нельзя. Запуск у себя работает без
дополнительных настроек.
