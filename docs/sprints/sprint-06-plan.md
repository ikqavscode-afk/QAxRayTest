# Sprint 6. План: укрепление и релиз

Статус: утверждён 2026-11-08, идёт. Скорость для планирования: около 28 SP (Sprint 1: 26, Sprint 2: 31, Sprint 3: 28,
Sprint 4: 28, Sprint 5: 28).

## Цель спринта

Выпустить `v0.1.0`: закрыть оставшиеся защитные пробелы веб-приложения и подготовить публичную демонстрацию на
безопасной цели.

| PB-054 | Финальный README, демонстрация на безопасной цели, релиз `v0.1.0` | 5 |

Порядок: PB-050 и PB-051 (малые, закрывают веб-часть), PB-052 (самая сложная, в середине), PB-053, затем PB-054.

## Критерии приёмки

- **PB-050:** POST-запросы `/check` и `/runs/<id>/stop` без действительного токена отклоняются; токен привязан к сессии,
  страницы остаются доступными с клавиатуры; тесты на отклонение чужого запроса.
- **PB-051:** предел запусков в единицу времени и одновременно; понятное сообщение при превышении; настройки в
  `QAXRAY_*` с жёсткими границами.
- **PB-052:** HTTP-клиент соединяется с IP, проверенным политикой (без повторного разрешения имени); тест на подмену
  DNS между проверкой и запросом; запись в ADR-0003.
- **PB-053:** ручная проверка скринридером и клавиатурой всех страниц, включая блок «Отчёты»; результаты записаны.
- **PB-054:** README соответствует поведению, пример демонстрации на безопасной цели вне репозитория, тег и релиз.

## Кандидаты сверх плана (по решению владельца)

PB-068 (недоступный сайт стоит около 50 секунд), PB-069 (остановка прерывает HTTP-запрос), запись версии Chrome в bug
report, постоянное хранение отчётов и учёт запусков (отдельное решение, ADR перед реализацией).

## Риски

| Риск | Реакция |
|---|---|
| DNS rebinding затрагивает HTTP-клиент и тесты | Сначала тесты с подменой разрешения имён, затем реализация |
| Демонстрация на чужом сайте | Только своя или явно разрешённая цель; список целей вне репозитория |
| Публичный запуск без ограничений | Не выпускать открытым сервисом (концепция); ограничения PB-050 и PB-051 обязательны |
