## Что сделано

**Безопасность и ядро**
- Политика адресов: только публичные адреса, проверка каждого редиректа и DNS-результата.
- Безопасный HTTP-клиент: лимиты размера, времени, числа редиректов, повторы только при сетевых сбоях.
- Чистая архитектура: ядро без Flask, requests и Selenium, адаптеры отдельно, корень композиции в одном месте.
- Статусы PASSED, FAILED, WARNING, SKIPPED, BLOCKED; эвристики не дают FAILED; причина обязательна.
- Маскирование секретов на всех границах: хранилище, консоль, страницы, журналы (проверено «канарейками»).
- Защита репозитория от токеноподобных строк (правило и тест-страж).

**Проверки (25 из 25)**
- Исходный HTML: QC-001…008, 011, 013.
- Браузер: QC-009, 010, 012, 014, 015, 016, 017…019, уточнение результатов по отрисованной странице; без Chrome
  проверки пропускаются (SKIPPED).
- API по GET: QC-020…025, ожидаемый статус по каждому пути, документация OpenAPI/Swagger JSON, сбой одного пути
  не блокирует остальные.

**Продукт**
- Веб-форма и консоль, подтверждение права на тестирование, поля API.
- Фоновые запуски, прогресс, остановка с закрытием браузера, результат по ссылке, страница каждой проверки.
- Черновик bug report: по одному на каждый FAILED, Markdown и JSON, «не подтверждено».
- Allure-результаты и архив .zip, проверено настоящим Allure Report.
- Настройки `QAXRAY_*` с жёсткими границами; стандарты интерфейса (доступность, сетка, цели нажатия) закреплены тестами.

**Качество и процесс**
- 936 автотестов, 16 необязательных (1 живой, 15 браузерных); `ruff`, `mypy` строго, проверка контента.
- CI и отдельное браузерное задание; сквозные тесты с имитированной сетью и заглушкой браузера.
- 12 решений в `docs/decisions` (ADR 0001–0012), бэклог, планы и ретроспективы по каждому спринту.

**Известные ограничения и долги**
- Результаты хранятся в памяти процесса (1 час).
- Остановка не прерывает уже идущий HTTP-запрос (PB-069); недоступный сайт отвечает около 50 секунд (PB-068).
- Документация API в YAML не читается (PB-060).
- Жёсткий обрыв приложения может оставить процесс Chrome.

**Запас идей (без спринта):** чтение YAML, лимит описания API выше 1 МБ, проверки контраста и размера целей в профиле,
состояния hover и disabled, ранний отказ от браузера для недоступного сайта. Вне MVP: несколько профилей,
мобильное и нагрузочное тестирование.
