## Оговорки (честно)

- Раздел «Быстрый старт для пользователя» вошёл в `main` после тега `v0.1.1`, поэтому в архив релиза не попал; исправляет
  задача PB-071 (`v0.1.2`).
- Приложение рассчитано на запуск на своём компьютере: готового публичного сервиса нет; требования к публикации на
  сервере записаны в [ADR-0016](../decisions/0016-web-hardening-and-deployment.md) и не реализованы.
- Интерфейс только на русском; скринридером вручную не проверялся (автоматические замеры доступности пройдены).
- Результаты не хранятся постоянно; решение о хранении и учёте запусков открыто (PB-074).
- Браузерные тесты с настоящим Chrome идут отдельным заданием CI и срабатывают при изменении браузерного кода или по
  расписанию.
