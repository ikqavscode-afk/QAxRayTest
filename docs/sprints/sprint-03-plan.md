# Sprint 3. План: браузер, основа

Статус: запланирован. Скорость для планирования: около 28 SP (Sprint 1: 26, Sprint 2: 31).

## Цель спринта

Безопасно открыть страницу в браузере и выполнить ограниченные проверки структуры и доступности,
не нарушая правил стабильности ([ADR-0002](../decisions/0002-statuses-and-stability.md)) и политики адресов.

## Критерии приёмки

- **PB-020:** ссылки того же домена, не более 10, только `GET` через `SafeHttpClient`; чужой домен не
  запрашивается; ссылки-заглушки пропускаются; нет ссылок: `SKIPPED`; сетевой сбой по одной ссылке не
  блокирует остальные.
- **PB-021:** проверки видят только порт `BrowserPort` (ядро не импортирует Selenium); адрес страницы
  проходит политику до открытия; только явные ожидания (`sleep` запрещён); лимит времени на страницу
  и на запуск; браузер закрывается всегда (в том числе при ошибке); сбой браузера даёт `BLOCKED`,
  а не `FAILED`; тесты ядра работают на заглушке порта без браузера.
- **PB-022…026:** результат `PASSED` или `WARNING` (эвристики), `SKIPPED` при неприменимости (нет форм,
  нет кнопок) с причиной; соблюдены лимиты из чек-листа (30 изображений, 20 нажатий Tab, 2 размера окна).
- **PB-028:** браузерные тесты в отдельном задании CI; быстрые тесты и их задание не зависят от браузера.

## Решения, которые нужно принять на планировании

| Вопрос | Предложение |
|---|---|
| Какой браузер и драйвер | Chrome и Selenium Manager (автоматический драйвер); другие браузеры позже через порт |
| «Обычное окно» из концепции или без интерфейса | По умолчанию режим без видимого окна в CI, видимое окно включается настройкой локально; решение записать в ADR-0007 |
| Как выбирать между результатом по HTML и браузерным | Откладываем до Sprint 4 (PB-027); в Sprint 3 браузерные проверки отдельные |
| Где хранить скриншоты как доказательства | Не в Sprint 3; доказательства пока строками, скриншоты в Sprint 5 вместе с `Redactor` |

## Риски

| Риск | Реакция |
|---|---|
| Браузер в CI нестабилен или недоступен | Отдельное задание, при неудаче не блокирует остальные; запасной план: локальный запуск и отметка в ретроспективе |
| Объём PB-021 больше 8 SP | Делим: порт и заглушка отдельно от адаптера Selenium |
| Страницы, медленные или тяжёлые | Лимиты времени и число элементов, `BLOCKED` при превышении |
