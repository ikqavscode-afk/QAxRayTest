# Sprint 7. План (проект): доступ для пользователей и основа для английской версии

Статус: **утверждён 2026-11-08, приостановлен** (ни одна задача не начата; состояние на паузе: [checkpoint-mvp.md](checkpoint-mvp.md)). Скорость для планирования: около
28 SP (Sprint 1: 26, Sprint 2: 31, Sprint 3: 28, Sprint 4: 28, Sprint 5: 28, Sprint 6: 19 при намеренно заниженном плане).

## Цель спринта

Сделать продукт доступным людям, у которых нет вашего компьютера: понятный старт, пример результата и способ заказать
демонстрацию; принять решения о хранении отчётов и подготовить основу для английской версии (международный рынок).

## Откуда задачи

Выводы после релиза `v0.1.1`: раздел «Быстрый старт для пользователя» вошёл в `main` позже тега `v0.1.1`, поэтому людям,
скачавшим релиз, он недоступен; пока приложение запущено только у владельца, другие не могут им воспользоваться;
хранение отчётов и язык интерфейса остались открытыми решениями.

## Предлагаемые задачи (22 SP, запас на хвосты)

| ID | Задача | SP |
|---|---|---|
| PB-071 | Выпуск `v0.1.2`: быстрый старт для пользователя попадает в релиз; проверка чистой установкой из релиза | 1 |
| PB-072 | Раздел «Попробовать» в README и пример результата (скриншоты, пример bug report и архива Allure по `example.com`, без личных данных) | 2 |
| PB-073 | Заявка на демонстрацию: шаблон формы GitHub Issues (дата и время с часовым поясом, цель, подтверждение права, способ ответа) и способ связи | 1 |
| PB-074 | ADR о хранении отчётов: где хранить полные отчёты, краткая и полная версия, учёт запусков, срок хранения, приватность | 2 |
| PB-075 | Слой сообщений: результаты проверок хранят ключ и параметры вместо готового русского текста; каталоги `ru` и `en`; выбор языка (основа перевода, ADR) | 8 |
| PB-076 | Английские тексты 25 проверок, интерфейса, bug report и Allure (проверка носителем языка) | 5 |
| PB-077 | Английская версия README и CHANGELOG | 3 |

Итого 22 SP. Порядок: PB-071 (малая, закрывает долг релиза), PB-072 и PB-073 (безопасные, без сервера), PB-074 (решение
до перевода: тексты в хранилище должны быть языконезависимыми), затем PB-075, PB-076 и PB-077.

## Критерии приёмки

- **PB-071:** в теге `v0.1.2` есть быстрый старт; чистая установка из релиза в пустую папку проходит (консоль и веб);
  CHANGELOG и версия обновлены; тег и релиз создаёт владелец после зелёного CI.
- **PB-072:** по README новый человек видит, что получит, не запуская; пример без личных данных и без чужих сайтов,
  кроме `example.com`; секреты в примерах отсутствуют (проверка контента).
- **PB-073:** форма открывается ссылкой из README; заявка не раскрывает личные данные в репозитории; поле подтверждения
  права на тестирование обязательно.
- **PB-074:** ADR принят владельцем; задачи реализации внесены в бэклог с оценкой; без кода хранения.
- **PB-075:** ни одна проверка не формирует русский текст в ядре; тест: каждый ключ есть в `ru` и `en`; статусы проверок
  не зависят от языка; страницы, консоль, bug report и Allure выводят выбранный язык; `<html lang>` соответствует языку.
- **PB-076:** переведено всё, что видит пользователь; терминология (PASSED, WARNING, BLOCKED и др.) согласована и
  записана; проверка носителем языка.
- **PB-077:** английский README соответствует русскому по содержанию, ссылки рабочие.

## Решения, которые нужно принять на планировании

| Вопрос | Предложение |
|---|---|
| Как показывать контакт | **Решено:** заявка через GitHub Issues, Telegram-канал `@shiftaeon` и личный контакт `@hugoray`; почта не используется. Пока контакты только в профиле GitHub, в README добавляются в PB-072 и PB-073 |
| Где и что хранить | Сначала ADR (PB-074): варианты (память, закрытая папка на сервере, закрытый репозиторий для выгрузки); Git для чужих данных не рекомендуется |
| Выпуск `v0.1.2` | Сделать сразу в начале спринта (малая правка, только документы и версия) |
| Английский: объём | Основа и тексты (PB-075, PB-076) в этом спринте; запуск ступени 2 (демо по записи с вашего ПК) и сервер не в этом спринте |
| Кто проверяет английские тексты | Носитель языка или вы; машинный перевод терминов не принимать без проверки |

## Риски

| Риск | Реакция |
|---|---|
| PB-075 затрагивает все 25 проверок и тесты | Сначала сквозной срез на 2–3 проверках и один ADR, затем остальные; тесты стражи на русские строки в ядре |
| Перевод до решения о хранении приведёт к переделке | PB-074 раньше PB-075 |
| Английские тексты неточны | Проверка носителем языка, список терминов |
| Обещание демонстрации без инфраструктуры | Честная формулировка в README: заявка на показ, а не постоянный сервис; ступень 2 отдельным спринтом |

## Что остаётся за пределами этого спринта

Демонстрация по записи с вашего компьютера (код доступа, список разрешённых целей, подтверждение владения сайтом,
баннер демо-режима), постоянный сервер с изоляцией Chrome и обратным прокси, прослушивание интерфейса скринридером
(задача владельца), пауза между повторами одной цели, PB-068, PB-069, PB-060, PB-066.
